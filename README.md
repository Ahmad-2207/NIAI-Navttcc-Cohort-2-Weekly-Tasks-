# NAVTTC AI / ML / DL Course: Tasks for Weeks 1 to 5

One folder per week, one file per task. File names match the task numbers in Annexure-I.

| Folder | Tasks | Topics |
|---|---|---|
| week_01 | 1 to 19, 21 to 25 | Installation, Linux commands, Python basics, conditionals, loops, list/tuple/string/set/dict |
| week_02 | 20, 26, 27, 49, 50 | Functions, exception handling, custom exceptions, mean/median/mode, standard deviation |
| week_03 | 28 to 40 | NumPy (arrays, indexing, slicing, dtypes, copy vs view, shape, reshape, iteration, join, split, search, sort, random) |
| week_04 | 41 to 48 | Pandas (basics, install, Series, DataFrame, read CSV, analysis, cleaning, correlations) |
| week_05 | 51, 52 | Linear regression, logistic regression (binary and multiclass) |

## How to run
```
python week_01/task_03_add_two_numbers.py
bash week_01/task_02_linux_commands.sh
```
Needs: numpy, pandas, matplotlib, seaborn, scikit-learn (see week_01/task_01_installation.md).

## Notes
- Tasks 28 to 48 are listed for weeks 3 and 4 in the sheet. NumPy tasks are in week_03 and Pandas tasks in week_04, following the weekly schedule.
- Tasks 3 to 14 use the code from the sheet. Task 10 originally had no print line, so one was added.
- Tasks 15 to 27, 41 to 48 link to online tutorials. These files contain original exercises on the same topics.
- Task 1 (installation) cannot be done from code, so it has step-by-step instructions plus a script that checks your install.
- Week 4 data files are in week_04/data. Weeks 4 and 5 also save PNG charts next to the scripts.
